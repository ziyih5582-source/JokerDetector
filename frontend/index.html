上海交通大学 · 思源湖

交心·思源湖研究所

一套给交大人的「谈心 + 自查」小机制：把一段聊天交给湖面，算法量你投入了多少， AI 读语气，钓翁陪你把没想明白的地方说出口。三件事一次做完——量一量、记下来、说出口。

不需要 API Key 也能完整体验；聊天数据默认只留在本机。往里走，水面上点一下还能喂鱼。

始三步就能用

  1. 一

    把聊天粘进来

    每行「发言者：内容」即可，也可以直接导入微信导出的 Excel。手边没有记录，就用内置的两个虚构示例先跑一遍。

  2. 二

    告诉湖面哪个是你

    点「辨认说话的人」，核对哪一边是你、哪一边是对方；顺手看一眼脱敏预览，就知道什么会被发出去。

  3. 三

    看水纹，也留下笔记

    结果页同时给出分数、五维墨线、双方比对，以及对方说过什么、有哪些互相矛盾的地方。

事这个研究所做的三件事

量一量 · 谈心分析

五维相对指标 + logistic 曲线，把你在这段关系里的投入折算成 0–100 分，并给出双方比对与依据。分数只描述你交上来的这一段聊天。

记下来 · 人物档案

把对方明确说过的喜好、以及一句句可核查的沟通观察，按人存成档案；正反冲突并存，随时可以人工修正、导出或删除。档案在本机加密保存。

说出口 · 找钓翁聊聊

不想分析、只想有人听着，就去找思源湖畔的钓翁。可以选定一个人，让 TA 的脱敏档案先被读过，建议就会贴着你这段关系，而不是泛泛安慰。

界它是什么，不是什么

这是一个课程作业里的小工具，用来自我觉察与整理，不是心理测量、不是诊断，也不能替代心理咨询或医疗。 分数和标签都只反映你交上来的那段聊天，不构成对任何人的判断。

如果此刻真的很难

  • 学校心理健康教育与咨询中心：通过校方公布的渠道预约（在校学生通常免费）。
  • 全国统一心理援助热线 12356，24 小时、免费；各地还有本地的心理援助热线。
  • 紧急情况请直接拨打 120 / 110，或立刻联系身边可信任的人。

热线与预约方式以官方公布为准，这里只是把入口放在顺手的地方。

        使用说明
        
      这个研究所到底能做什么
      
        
      一句话：把一段聊天变成两份东西——一份量化的关系画像，一份关于对方的笔记。这一页讲清每处怎么点、数字怎么来的、什么会被发到云端。
      
      
      

      
      

      
      一一分钟上手
      
      
        
        
      1. 在顶部点「谈心分析」，把聊天粘进文本框（每行「发言者：内容」），或导入微信导出的 Excel，然后点「辨认说话的人」。
        2. 
        
      2. 核对「我（自己）」和「对方」；想让湖面记住这个人，就在右栏选一个档案、或新建一个，并勾选第一项确认。
        3. 
        
      3. 点「开始分析」。结果页会同时给出水纹（分数、类型印章、五维墨线、双方比对）与档案变动（新增了哪几条喜好、有没有互相冲突）。
        4. 
        
      4. 只想分析、不留痕迹，就把「这段聊天记在谁名下」留成「不建档」。想找人说说话，去「找钓翁聊聊」。
        5. 
      
      
      
      没有 API Key 也能走完整个流程：解析、统计、脱敏、喜好提取全在本机完成，一次网络请求都不会发出。
      

      
      二这是一套什么样的"谈心机制"
      
      
      三件事按顺序做，正好对应三个页面；只做其中一件也成立。
      
      
      
        
      
          
      ① 量一量 · 谈心分析
      
          
      把模糊的「我是不是付出太多」变成可比较的数字：五个维度的相对值合成 0–100 分，并给出双方比对。它的作用是把感觉说清楚，而不是给你定性。
      
        
      
        
      
          
      ② 记下来 · 人物档案
      
          
      关系里的失望常常来自「记错了」。档案按人保存对方明确说过的喜好与可核查的观察，正反冲突并存，随时可修正——它帮你看清这段关系，而不是替对方画像。
      
        
      
        
      
          
      ③ 说出口 · 找钓翁聊聊
      
          
      有些事需要有人听着。钓翁不做诊断、不贴标签、不替你决定分手或复合，只帮你把情绪接住、把选项看清。真到了需要专业帮助的时候，下面有更合适的入口。
      
        
      
      
      

      
      三七个页面各管什么
      
      
      
        
      
          
      首页
      
          
      入口。一张思源湖水彩，下面写着三步上手；点纸面之外的地方不会有任何副作用，安心乱点。
      
        
      
        
      
          
      谈心分析
      
          
      唯一的输入口。粘贴文本或导入 Excel、辨认说话的人、核对脱敏预览、决定这次是否写进档案、是否调用云端 AI。示例按钮可以先用虚构内容跑一遍。
      
        
      
        
      
          
      分析结果
      
          
      结果页。给出分数与判定、类型印章、五维墨线、双方比对，以及本次的档案变动与可选的 AI 情感长文。可以「导出为图片」留档。
      
        
      
        
      
          
      找钓翁聊聊
      
          
      和 AI 聊感情问题。可以只随便聊，也可以选定一个人、把 TA 的脱敏档案作为背景交给 AI。随时可「新对话」，对话只存在浏览器内存里。
      
        
      
        
      
          
      人物档案
      
          
      按人累积「喜好」与「沟通观察」，每条都保留脱敏依据，正反冲突并存，可以人工确认、修正、删除，也可以导出 JSON。档案在本机加密保存。
      
        
      
        
      
          
      心理学依据
      
          
      依恋理论、爱情三角、投资模型等经典理论，每条都带出处与证据强度，并说明它对应本项目里的哪个指标。用来理解关系，不用来给人贴标签。
      
        
      
        
      
          
      设置
      
          
      查看云端 AI 是否就绪（密钥放在服务端项目根目录 .env 的 DEEPSEEK_API_KEY 里，页面只显示状态），以及湖面动画、撒食与背景音乐。
      
        
      
      
      

      
      四分数是怎么算出来的
      
      
      
      
      五五维各看什么
      
      
      
      
      六判定区间
      
      
      
      
      分数只描述所提交的这一段聊天，会随片段长短与选谁当「我」而变。桌面版 legacy/desktop/v5.py 与网页版用的是同一套算法（五维 Z 指标 + logistic，同为 0–100 分），只是判决树的写法略有不同；真正过时的「比率制」（0.2 / 0.5 / 1.0 / 2.0 分档）属于更早的 v1 / v3 / v4.x，那些代码已随 archive/ 一并删除。
      

      
      七四种类型
      
      
      
      
      

      
      八什么留在本地，什么会发出去
      
      
      
        
      
          
      只在本机
      
          
      Excel 解析、统计与打分、手机号/邮箱等基础脱敏、喜好提取、档案加密存储（data/private/）。完整聊天内容不会进入档案库，也不写进数据库。
      
        
      
        
      
          
      勾选后才走网络
      
          
      「本次使用云端 AI」——发送脱敏后的片段去提取喜好与生成情感长文；「找钓翁聊聊」——发送你说的话，以及你勾选的那个人的脱敏档案背景。两处都会在页面上先给你看要发什么。
      
        
      
        
      
          
      从不保存
      
          
      钓翁的对话只留在当前标签页内存里，刷新即消失，服务端不落盘。云端密钥也只留在服务端（.env 或同名环境变量），不会下发到浏览器。
      
        
      
      
      

      
      九输入格式与上限
      
      
      

      
      十常见问题
      
      
      
        
      没有 API Key 能用吗？
      能。除了「找钓翁聊聊」必须联网，其它功能都能离线完成，包括喜好提取与档案管理。
      
        
      为什么 AI 一直不可用？
      去「设置」看状态：网页版不需要你填 Key，密钥统一放在服务端项目根目录的 .env 的 DEEPSEEK_API_KEY 里。改完 .env 点「重新加载配置」，再点「测试连接」；只有真实请求成功才会标为已验证，失败时页面会给出具体原因（密钥、余额、模型 ID、限流、超时等）。
      
        
      为什么两次分析的分数不一样？
      分数只反映你这一次提交的那段聊天。片段越短、双方越不对等，分数越容易走极端；换一个片段、甚至把「我」和「对方」换了，都会变。
      
        
      为什么类型会跳来跳去？
      类型取的是五维里数值最高的那一项，不同片段的「最高项」很可能是不同的维度，所以类型会变。它更像一句总结，不是人格标签。
      
        
      为什么没有认出任何喜好？
      本地提取只认明确的第一人称日常喜好（「我喜欢徒步」这类）。复杂表达、反讽、生日与关键事件都不在覆盖范围内，宁可留白也不乱猜。想让 AI 帮忙推断，就勾选云端 AI。
      
        
      重复导入同一段聊天会怎样？
      同一段脱敏片段按指纹去重：档案不会重复记账，也不会重复调用云端。除非上次 AI 失败，或者你这次额外勾选了生成情感长文。
      
        
      AI 长文没出来？
      结果页会显示具体原因，本地统计仍然保留。常见原因是超时（长文有独立的 90 秒超时）、额度不足或模型 ID 与服务商不匹配。
      
        
      这些数字能当诊断用吗？
      不能。这是一个课程作业里的趣味算法，标签和分数都不是心理测量工具，也不能代表任何人的感情或人格。如果你正处在持续的痛苦里，请去看「首页」最下面的求助入口。
      
      
      

      
      本项目仅供课程学习与娱乐，请勿用于真实情感决策。如果你正处在持续的痛苦里，寻求现实中的专业帮助比任何算法都重要。
