# 前端 · 交心 · 思源湖研究所

站名是**「交心 · 思源湖研究所」**（副标题：上海交通大学 · 把一段聊天投进湖里，量一量、记下来、说出口），一套校园「谈心 + 自查」小机制，三件事按顺序做完：**① 量一量**（谈心分析）· **② 记下来**（人物档案）· **③ 说出口**（找钓翁聊聊）。首页显眼处写明它**不是心理测量、不是诊断**，并把校内心理健康教育与咨询中心、全国统一心理援助热线 12356 与 120 / 110 放在顺手的地方。

纯静态页面，没有构建步骤、没有 npm 依赖、没有外部 CDN：直接用浏览器打开由后端挂载的 `/` 即可，也可以整目录丢到任意静态托管。

```
frontend/
├── index.html          # 单页结构：首页 / 谈心分析 / 分析结果 / 找钓翁聊聊 / 人物档案 / 心理学依据 / 使用说明 / 设置
├── favicon.svg         # 标签页图标：朱砂方印里一个「心」字
├── css/ink.css         # 水墨样式：细墨线、浓淡墨色、朱砂点缀，湖色打底，没有方框与色块
```

## 页面与导航

导航共七个去处：**首页**（`pond`）· **谈心分析**（`flow`）· **找钓翁聊聊**（`fisherman`）· **人物档案**（`book`）· **心理学依据**（`theory`）· **使用说明**（`guide`）· **设置**（`config`）。此外还有一个**不在导航里**的结果页**「分析结果」**（`result`，仍保留「水纹」这个别称），由「开始分析」后自动切过去；在结果页时导航会把下划线留在「谈心分析」上。导航最左有一处「你在这里」指示（`#nav-here`），由 `ink.js` 的 `go()` 按 `VIEW_LABELS` 写入当前页面名，所以页面名与按钮名始终对得上。

视图切换靠 `<body data-view="...">` + CSS 显示规则，**没有 hash 路由**：浏览器后退不切视图，URL 也不反映当前视图。

## 首页画卷与鱼

- **首页是画卷**：`../assets/pictures/交大思源湖.png` 是原图（因体积与版权原因**不入库**），网页用的是由它导出的 `img/siyuan-lake.jpg`（首页画卷）与模糊压暗的 `img/siyuan-lake-soft.jpg`（整站远景水色，以及首页中段那条「卷中题记」水色横带）。换成自己的照片时，按同样两个文件覆盖即可。
- **鱼只在首页之外出现**：`body[data-view="pond"]` 时 `#pond-canvas` 是透明的（湖色远景 `#lake` 同样只在别的页面透出），所以首页不会出现鱼；切到其它页面后，点在纸面空白处即可撒一把食，附近的鱼会游过来吃掉——点在按钮、链接、输入框等控件上不会触发。「设置」页另有「暂停湖面动画」与「撒一把鱼食」两个开关。

## 与后端的关系

前端只通过 `/api/*` 与后端通信，并加载 `/static/*`（自身资源）与 `/music/*`（背景音乐）两类静态路径：

- 开发/单机：后端把它们一起挂载（见 `backend/app/main.py`），打开 <http://127.0.0.1:8000/> 即可。
- 分离部署：把本目录放到 Nginx / 对象存储，把 `/api`、`/music` 反向代理到后端。

> 注意：JS 里的接口路径是绝对路径（`/api/...`），所以前端与后端最好同源；若要跨域，需要反向代理或改 `js/ink.js` 里的 `api()` 前缀。

## 约定

- 页面数据尽量从后端取（阈值、权重、指标说明读 `/api/guide`），避免文档与判定逻辑各写一套。
- 不使用内联脚本与外部资源，页面因此可以启用严格 CSP。
- 背景音乐从 `/api/music` 读取文件名，再把 `<audio>` 指向 `/music/<文件名>`；曲目缺失时只是没有音乐。
