# 沟通记忆 v3：安装、使用与已验证范围

版本日期：2026-10-08。开发基于你当前的 `D:\project\JokerDetector` 源码。本轮在独立源码副本完成，没有替换该目录，也没有上传GitHub。

## 1. 这次实际改了什么

正常“谈心分析”的档案更新现在默认调用新的沟通识别服务，档案页也使用同一服务。新的AI任务关注请求、边界、本次支持需要、情境特点、共同理解与澄清、阶段、重要事件及有实际用途的偏好。普通咖啡/电影清单不再是主流程的核心输出。

模型阅读双方发言，区分事实、可能解释、可尝试方式。程序检查引用、归属、条件、时间、删除和版本。首次实测发现“双方”写成both与协议不一致，已安全归一化为relation，仍要求双方依据；没有放宽引用真实性要求。

档案首页优先显示少量相处方法。关系资料折叠为选填，用一句话即可补充或修正认识。修正或删除使旧方法失效，AI不静默覆盖用户补充。

问钓翁在用户勾选档案背景时，按当前问题筛选可用信息；发送前取得本次背景预览，签名绑定人物、问题和档案版本，实际发送使用同一文本。信息不足与待确认内容不作为确定背景。

原有聊天统计、五项指标、判定与长文朗读逻辑保留。旧喜好资料仍在展开记录中，旧API显式使用profile_engine=legacy时保持兼容；网页与主统一API默认使用communication。

## 2. 更新包如何安装

这是更新包，需要现有完整项目。新包采用平铺目录，Windows默认解压后，install_update.py就在解压目录第一层。

1. 停止原服务（运行终端Ctrl+C）。
2. 备份原项目，尤其整对备份私人档案的数据库与profile.key。自定义JOKER_PROFILE_DIR时备份对应目录。
3. 在更新包目录运行检查，再运行安装。实际项目路径已确认为D:\project\JokerDetector，project没有s。

```powershell
py install_update.py "D:\project\JokerDetector" --check
py install_update.py "D:\project\JokerDetector"
```

脚本核对已检查的源码版本与包内校验值，安装时备份被替换文件。若显示Your versions differ，会停下且不写文件，避免覆盖队友新修改。备份位于项目.dossier-backups目录，保留备份名。

没有新增必装依赖，可以使用已有.venv。建议先用隔离档案目录检查：

```powershell
cd "D:\project\JokerDetector"
$env:JOKER_PROFILE_DIR = "$pwd\data\private-communication-v3-test"
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开http://127.0.0.1:8000，Ctrl+F5刷新，进入人物档案。原.env和API配置不会被安装脚本覆盖。自定义测试目录与源码备份不要提交GitHub。

## 3. 怎样使用

1. 新建或打开一个人；标签不必先填。
2. 展开“上传新聊天”，粘贴每行“发言者：内容”，或导入Excel/截图。
3. 核对我与对方；有可靠聊天日期再填写，不知道留空。多天聊天请分段。
4. 勾选AI理解时使用现有服务；对应确认同时说明发送与保存范围。一次点击“理解聊天并更新档案”。
5. 看本次重要变化与方法卡。展开依据可核对原话及条件。
6. 不准确时点“这条需要修正”，写一句话即可。补充默认仅本地；若愿意供已授权的档案背景使用，单独勾选。

例子：

```text
我：这次展示你负责第二部分可以吗？
小林：能不能以后分工把哪部分、几点前要一起说清楚？
我：我把口误截图发群里逗大家？
小林：别在群里拿我开玩笑。
```

预期：分工时说清负责部分和截止时间；群内避免针对个人的玩笑。不能把群内边界扩大成禁止所有群聊内容。重复处理不重复计数；空结果只缓存私有输入指纹，不造条目或空更新记录。

第二段可用：

```text
我：快点交吧，不是说这周吗？
小林：我以为这周是初稿，你现在要最终版？
我：是我没说清，周三初稿、周五最终版。
小林：哦，那周三我先给你初稿。
```

完整AI模式应保存这次理解差异与澄清，形成明确交付物与时间的参考方法。规则模式不具备这种完整理解能力，不应把没有结果误当成AI已分析。

## 4. 已验证的效果与限制

### 真实模型小范围调试

使用你已配置的api.deepseek.com / deepseek-v4-pro，仅发送虚构开发案例。严格使用12次请求：1次旧识别器对照、9个新连续输入有效结果、2次字段协议不一致而被程序拒绝的响应。所有请求都计入预算，之后没有追加API调用。累计使用量为14,278 tokens；费用以服务商账单为准，不按这个数估算金额。

- C01：旧识别器在第一段没有留下分工要求，新识别器留下明确要求；第二段保持同一项；第三段记录初稿/最终版的理解差异与澄清。
- C02：识别群内边界并补充任务讨论例外。模型曾把方法扩大到所有涉及对方的群内容，也曾将私下例外作为直接细化。程序已收窄个人玩笑范围，并保留公开边界与私下条件分支。
- C05：12号改15号；补传较早的12号记录不覆盖15号。模型曾将旧记录建议为冲突，程序根据可靠发生日期处理为历史。

修订期间提示与程序约束有变化；修订后的范围、分支和时间行为通过已保存的真实虚构输出离线重放确认。不是最终版本对全部30案例的独立模型验收，也不是识别准确率或情商改善证明。

### 程序与浏览器检查

后端测试结果见随包README；新增测试覆盖请求与条件、混合转述中的本人要求、双方引用、重叠原文的必要上下文、事件身份与日期、原始资料改用AI、私人补充、修正/删除、旧API兼容、背景一致性、已保存模型结果重放等。朗读10项通过，Ruff通过。

无头Edge检查了方法优先、折叠管理、重复导入、修正后旧方法停用、删除、文本安全、390px手机宽度及原聊天分析。页面还展示了实测虚构AI结果形成的四张方法卡，展示不追加模型请求。

### 仍需注意的实际边界

AI仍可能漏掉含义或扩大条件；程序能验证引用真实，不能证明所有解释正确。只有三组开发案例的真实调试，不能承诺对陌生场景同样准确。

第一版本地规则只摘录少量明确表达；语义理解需要AI。相同主题的语义匹配依赖模型，事件身份不清或时间未知会保守处理。未确认的内容不形成确定方法。

人物特点保留自述与范围，没有诊断、好感推断、练习模拟或保证沟通结果。临时与事件资料不因为日期过去就自动宣布成功或结束。

私人数据仍是本机单用户的加密保存，尚未实现公开网站需要的账号与用户隔离，也不自动收集研究样本。

## 5. 给开发者的接口与测试

核心：services/communication.py负责提示、引用/范围验证、时间、更新、卡片和相关筛选；communication_flow.py负责共享流程。新schema与路由保持与评分实现分开。

```text
POST /api/profiles/contacts/{id}/memory/import   识别并原子更新
POST /api/profiles/contacts/{id}/memory/preview  只读更新预览
POST /api/profiles/contacts/{id}/memory/commit   提交签名预览
POST /api/profiles/contacts/{id}/memory/notes    用户自然语言补充/修正
POST /api/fisherman/context                     按query预览并签名背景
```

MemoryImport沿用messages、自身/对方名称、revision、chat_date与scene；增加save_consent以及可选source_kind、role_reliability、time_reliability。未核对人物拒绝提炼；AI摘要不当新证据；不可靠时间不作为日期锚点。

资料只保存必要脱敏片段与定位，不保存整份原始文件。显示“原话”不意味着完整匿名；导出JSON为明文，需自行保管。内部哈希与去重标识不进入公开档案返回。

```powershell
cd "D:\project\JokerDetector\backend"
..\.venv\Scripts\python.exe -m pip install pytest ruff
..\.venv\Scripts\python.exe -m pytest
..\.venv\Scripts\python.exe -m ruff check app tests\test_communication.py
```

test_communication.py里的记录重放不调用API。fixtures/communication_model_recordings.json全部虚构，包含已保存模型输出及来源。旧接口回归明确指定legacy；另有默认communication的真实接口测试，验证新入口与分数计算分离。

scripts/check_communication_live.py默认不调用API；--live才联网，会产生费用。它使用给定的虚构inputs资料，计数文件先记录再发送，失败也计数，最多12次且SDK重试关闭；同一输出文件保留已用预算。不应用真实私人聊天跑这个工具，也不把含配置的环境文件放进测试资料。
