# 人物档案 v8.4：追加核验与本地使用

2026-10-20。本轮是在 v8.3 基础上的一次独立复核，新增 API 预算上限为 **500,000 token**，没有改动前轮账本。

## 1. 这次交付了什么

- 保留“性格与相处画像 → 值得记住 → 少量沟通建议”的结构。画像先概括特点，再用简短解读说明；依据、范围及其他解释折叠，可切换双方。
- 两个人各自的爱好、生日、任务不能因为被模型标成“共同主题”就合并。候选结果和旧版缓存都核对证据所属人物；确有共同记录的事项仍可合并。
- 合并不成立时，双方明确、持续且有用的兴趣分别留下，不会全部降为历史碎片；一次性的偶发细节仍降低优先级。
- 修正格式检查误删解读的问题：通常保留两三句；一个内容完整的复句也可通过。证据、人物归属和内容核查仍照常执行，不为凑句数添加动机或性格。
- 提示模型用“对方”“我”明确人物，避免“自己”的歧义。这个提示不能保证每次生成都无歧义，见下方限制。

顶部导航、单次评分口径、OCR 与队友模块继续沿用已有接口。本轮没有把人物档案拆成五种场景模块。

## 2. 实际测试范围与计数

| 项目 | 本轮结果 |
| --- | --- |
| API 预算上限 | 500,000 token |
| 服务商报告用量 | **474,079 token**，约为上限的 94.8% |
| 实际模型请求 | **140 次**，均返回成功；包含多阶段提取、核查、综合及定向复测 |
| 实际跑完的独立案例 | **22 组**；重复复测不另算一组 |
| 模型 | 本机配置的 DeepSeek，测试时返回的配置名为 `deepseek-v4-pro` |
| 后端回归 | **470 项通过，0 失败、0 跳过** |
| 前端现有逻辑回归 | **21 项通过**：朗读 10 项、小丑看板 11 项 |
| 静态检查 | 后端 Ruff 通过，档案 JavaScript 语法检查通过 |

准备了 30 组候选案例，实际完整执行 22 组；其余 8 组因阶段预算预留未发送，**不计入已测试样本**。仓库新增的 `backend/tests/fixtures/archive_recheck_20261020.json` 含 18 组虚构补充材料，其中 10 组完成本轮云端测试，8 组尚未执行；它不是一个已全部跑过或有人格真值的基准集。

本轮仅发送虚构文本，没有重新向模型发送私人联系人聊天、真实截图，也没有重新测试 OCR。覆盖短聊、连续上传、旧聊天后上传、长文本与密集转述；长文本包含一组约 1.1 万字的密集上下文。长聊另做了一次基于已经保存的虚构来源片段的显式综合恢复，因此不能把综合恢复计成一次全新的完整上传测试。

## 3. 复核发现与修复

**双方信息归属。** 新增两人分别追不同作品、两人生日不同、双方分别承担相似任务等案例。复现了“relation 分类绕开归属检查”的问题，随后补上候选和旧缓存两处检查，并增加回归。复测中两部作品分别归到对应人物；自己承担的工作没有变成对方待办，也没有因此生成催促对方的建议。

**性格不应因格式被清空。** 一段有证据支持的完整复句，原来因为只有一个句号被删掉。现在保留这类有效解读，并用实际出现过的句子增加本地回归。没有解除证据核查，也没有强迫每段聊天都产出人格标签。

**时间、边界与关系状态。** 复核了农历生日和待核对公历日期、生日主人、群体见面许可、询问与接受的区别、单方面纪念日、任务取消、旧记录的上传顺序等。未确定的公历日期保持未确认，不把群体许可扩展成私下约会，不把单方面记念当成双方认可的纪念日。

最终保留的 22 组结果，自动硬性检查没有发现重复计费、来源原话不匹配等命中。另有两条人工复核提示：一条把应属于“我”的任务预期成“对方”，输出归属本身正确；另一条兴趣信息充分但没有产出大性格结论，保留为合理的暂不推断。**这些检查不等于人格准确率，也不等于逐句无误。**

## 4. 仍然要继续看的问题

1. 个别短聊天只足以推断沟通风格，未必能推断稳定的大性格；部分标题仍偏通用。下一轮应请用户对“是否像这个人、是否提供新认识”做独立评价，不能只依靠模型自查。
2. 长聊的主题压缩仍可能出现代词歧义。例如一次虚构生日聚会的安排，人物归属与分工有记录，但摘要中的“自己”仍需进一步消歧。提示约束只能减少这个问题，不能宣称已经完全解决。
3. 本轮只有一种服务商配置、以开发者构造的文本为主，没有独立盲测、跨模型对照、真实用户留存或沟通改善数据；不能据此声称心理测量效度或现实效果。
4. 云端 API 返回成功并不代表语义正确。识别版本升级和缓存兼容只控制部分工程错误，新材料仍可能提取不全；重要日期、关系态度与承诺应继续允许用户核对和纠正。

## 5. 本地怎么查看

- 正常使用：在项目根目录双击 `start.bat`，打开终端打印的地址。
- 独立预览：双击 `start-archive-next-preview.bat`，打开 `http://127.0.0.1:8021/profiles`。它使用 `data/archive-next-preview/`，与默认档案目录分开；首次克隆不会附带开发机上的示例或私人档案。
- 旧档案可先查看；需要生成新版内容时再上传新材料，或使用已有的显式重整入口。单纯打开预览和展开依据不会请求云端 AI。
- 本机已有资料和密钥不随代码更新覆盖。经同意留存的脱敏原话片段仍在本机加密保存，用于持续核查；这并不等于已经具备公网多用户隔离。
