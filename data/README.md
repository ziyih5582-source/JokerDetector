# 运行时数据

| 目录 | 内容 | 是否入库 |
| --- | --- | --- |
| `samples/` | 虚构聊天样例，用于手工试跑导入流程 | 入库（`test1.xls` 是真实私人记录，已忽略） |
| `private/` | 加密的联系人档案库 `profiles.sqlite3` 与密钥 `profile.key` | 不入库 |

## private/

- 由 `backend/app/services/profiles.py` 读写，脱敏后加密；**备份或换机时数据库与密钥必须一起带走**，只留其一无法解密。
- 想换存放位置，设环境变量 `JOKER_PROFILE_DIR` 指向别的目录即可（测试就是这么隔离的）。
- 聊天原文不写进这里，档案里只有提取出的喜好与观察条目，且都可以在「名册」里人工修正或删除。
