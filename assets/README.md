# 本地媒体资源（不入库）

这两个目录里的内容因版权原因**刻意不提交**，克隆仓库后请自备同名文件。缺少时程序照常运行，只是没有配乐与配图。

## music/

放 mp3（也可放 wav / ogg）。后端 `/api/music` 会列出目录里的音频文件名，前端判定完成后自动挑一首播放。

判定类型与曲目的对应关系写在 `backend/app/services/analyzer.py` 的 `JOKER_TYPES` 里（字段 `music`），当前使用：

| 类型 | 期望文件名 |
| --- | --- |
| 殉道型 | `过火.mp3` |
| 镜像型 | `一直很安静.mp3` |
| 弄臣型 | `怪咖.mp3` |
| 幻恋型 | `水星记.mp3` |

## pictures/

类型配图（字段 `image`：`殉道型.jpg`、`镜像型.jpg`、`弄臣型.jpg`、`幻恋型.jpg`）。
网页版目前不使用类型配图（用墨色印章代替），这一目录主要是给历史桌面版 `legacy/desktop/v5.py` 用的。

`交大思源湖.png` 是首页画卷（「交心 · 思源湖研究所」）的原图，同样**不入库**；网页实际加载的成品在 `frontend/img/` 里——`siyuan-lake.jpg` 作首页画卷、`siyuan-lake-soft.jpg` 作整站远景水色与「卷中题记」横带，都由这张原图导出。缺了原图不影响网页显示，只是没法重新导出。
