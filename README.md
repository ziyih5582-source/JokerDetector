## 📖 项目简介

你是不是在感情中付出太多却得不到回应？你是不是那个永远在主动的"小丑"？

**Joker Detector Pro** 是一款专为工程学导论课程设计的聊天记录分析工具。它能够：
- 📊 从微信聊天记录 Excel 文件中提取数据
- 🧮 使用多维度算法量化你的"小丑指数"
- 🤖 结合 AI 大模型进行情感关系深度分析
- 💌 生成个性化情感疏导建议
- 🎮 提供"恋爱冷静期"干预弹窗

> ⚠️ 本项目仅供课程学习和娱乐目的，请勿用于实际情感决策。

## ✨ 核心功能

### 1. 数据解析与统计
| 统计维度 | 说明 |
|---------|------|
| 消息数量 | 统计双方消息总数，计算发送比例 |
| 表情包数量 | 检测 `[emoji]` 格式表情 |
| 图片数量 | 检测 `[图片]` 标记 |
| 连续消息数 | 分析消息连续发送的最大 streak |
| 语音/通话记录 | 检测通话行为并施加惩罚系数 |

### 2. 算法评估系统
采用五维度比率综合评分：

```
r1 = 自己的消息数 / 对方消息数
r2 = 自己的表情包数 / 对方表情包数
r3 = 自己的最大连续消息数 / 对方的最大连续消息数
r4 = 自己的总字数 / 对方总字数
r5 = 自己的图片数 / 对方的图片数

jokernum_alg = (r1 + r2 + r3 + r4 + r5) / 5
```

### 3. AI 双重评估
- **小丑指数 AI**：调用大模型分析对话内容，给出 0-1 的小丑评分
- **最终指数** = 算法评分 × AI 评分

### 4. 情感人格类型 (MBTI 风格)

```
dim1: I/P - 主动发起型 / 被动回应型
dim2: E/R - 表达丰富型 / 含蓄克制型
dim3: D/S - 深度表达型 / 浅层交流型
dim4: T/F - 执着纠缠型 / 随性洒脱型
```

典型组合示例：
- 🃏 **IEDT** → 『深情表演家』
- 🃏 **IRDF** → 『沉默的守望者』
- 🃏 **PESF** → 『气氛组选手』

### 5. 情感疏导 AI
基于聊天记录生成 200-300 字的温柔情感疏导，包含：
1. 情绪安抚与认可
2. 问题分析与指出
3. 2-3 条可执行建议

### 6. 恋爱冷静期弹窗 🆕
当检测到高风险小丑行为时，触发全屏红色警告：
- 要求用户输入"我不是小丑" 5 次
- 每次输入错误都会弹出"错误"提示
- 冷静成功后解除警告

## 🚀 快速开始

### 环境要求
- Python 3.8+
- pandas
- openai
- httpx
- tkinter (Python 内置)

### 安装依赖

```bash
pip install pandas openai httpx
```

### 使用步骤

#### 准备聊天记录
1. 在微信电脑端打开目标聊天
2. 设置 → 导出聊天记录 → 选择 Excel 格式
3. 保存为 `chat.xlsx`

#### 运行分析

```bash
python final_v1.py
```

程序会提示：
```
请输入 Excel 文件路径（例如：chat.xlsx）：
请输入你是哪一个（0 或 1）：
```

#### 冷静期弹窗（可选）

```bash
python jokerTset.py
```

## 🎯 判定标准

| jokernum 范围 | 判定结果 | 含义 |
|-------------|---------|------|
| > 2.0 | 🤡 确诊纯小丑 | 情感投入严重失衡，请立即清醒！ |
| 1.0 ~ 2.0 | 😬 高度疑似小丑 | 比对方主动太多，存在自我感动风险 |
| 0.5 ~ 1.0 | 😐 轻度小丑倾向 | 偶尔失衡，但总体可控 |
| 0.2 ~ 0.5 | 🙂 健康社交模式 | 关系基本对等，继续保持 |
| < 0.2 | 😎 绝对理性人 | 可能是这段关系里的冰冷主宰 |
